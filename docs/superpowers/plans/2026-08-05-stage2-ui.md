# American Rails Stage 2 — Hotseat UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]` tracking. Consult frontend-design for the Board-Game-Arena aesthetic when styling.

**Goal:** A single-browser (hotseat / pass-and-play) React app that renders the American Rails board and full game state Board-Game-Arena style, and lets a local group click through an entire game — using the Stage 1 engine unchanged as the rules authority.

**Architecture:** React + TypeScript + Vite. One React state holds the engine `GameState`; every UI action calls `applyMove` and replaces the state. The board renders as SVG from a coordinate-based board definition. `legalMoves` drives what is clickable for the active player. No network yet (Stage 3).

**Tech Stack:** React 18, Vite 5, TypeScript strict, SVG. Engine imported from `src/engine`.

## Global Constraints
- Engine stays UI-agnostic: no React imports in `src/engine`. UI reads state and calls `applyMove`/`legalMoves` only.
- Hotseat model: one screen shows the current player's options; a "pass device to <name>" affordance separates turns.
- Board data is coordinate-based so hexes both render and compute adjacency from one source.
- Keep components small and focused (one responsibility each).

## File Structure
```
index.html, src/main.tsx, src/App.tsx, src/styles.css
src/engine/board/hexGrid.ts        # coord-based board builder + pixel geometry (+ test)
src/engine/board/americanRails.ts  # the REAL board, transcribed from the render
src/ui/
  useGame.ts            # React hook: holds GameState, exposes act(move)
  Board.tsx             # SVG hex map; highlights legal targets; click handlers
  Hex.tsx               # one hex (terrain fill, city label/values, cubes, dev marker)
  CompanyPanel.tsx      # per-company card (treasury, income, shares, cubes)
  PlayerPanel.tsx       # per-player card (money, shares, active marker)
  ActionBar.tsx         # action-track + year + whose-turn + action buttons
  AuctionPanel.tsx      # bid / pass UI when an auction is live
  Log.tsx               # scrolling action log
  Lobby.tsx             # new-game setup (names, seed) -> createGame
```
